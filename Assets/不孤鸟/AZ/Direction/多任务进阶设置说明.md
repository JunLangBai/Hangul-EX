# 多任务进阶难度 - 设置UI配置指南

## 📋 已完成的代码修改

### 1. AllSettingCtr.cs
已添加以下全局设置参数：
- `multiTaskRoundDuration` - 每回合时长（默认5秒）
- `multiTaskTotalRounds` - 总回合数（默认40）
- `multiTaskGesturesPerSide` - 每侧显示的手势数量（默认1，范围1-3）
- `multiTaskFeedbackDelay` - 反馈延迟时间（默认1.5秒）

### 2. MultiTaskAdvancedSettings.cs（新建）
设置脚本，包含4个方法：
- `OnRoundDurationSliderChanged(float)` - 回合时长滑块回调
- `OnTotalRoundsSliderChanged(float)` - 总回合数滑块回调
- `OnGesturesPerSideSliderChanged(float)` - 每侧手势数量滑块回调
- `OnFeedbackDelaySliderChanged(float)` - 反馈延迟滑块回调

### 3. MultiTaskAdvancedManager.cs
已更新Start()方法，自动从AllSettingCtr加载设置参数

## 🎨 在Unity中配置设置UI

### 步骤1：打开设置场景
打开 `ExcutiveReady` 场景（或你的设置场景）

### 步骤2：创建设置面板
在场景中创建或找到多任务进阶的设置面板，添加以下UI元素：

#### UI元素列表：

1. **回合时长滑块**
   - 创建 Slider 组件
   - Min Value: 3
   - Max Value: 10
   - Whole Numbers: 关闭
   - Value: 5
   - 添加Text显示当前值
   - 在OnValueChanged事件中：
     - 拖入挂载了MultiTaskAdvancedSettings的GameObject
     - 选择函数：`MultiTaskAdvancedSettings.OnRoundDurationSliderChanged`

2. **总回合数滑块**
   - 创建 Slider 组件
   - Min Value: 10
   - Max Value: 100
   - Whole Numbers: 开启
   - Value: 40
   - 添加Text显示当前值
   - 在OnValueChanged事件中：
     - 拖入挂载了MultiTaskAdvancedSettings的GameObject
     - 选择函数：`MultiTaskAdvancedSettings.OnTotalRoundsSliderChanged`

3. **每侧手势数量滑块**
   - 创建 Slider 组件
   - Min Value: 1
   - Max Value: 3
   - Whole Numbers: 开启
   - Value: 1
   - 添加Text显示当前值
   - 在OnValueChanged事件中：
     - 拖入挂载了MultiTaskAdvancedSettings的GameObject
     - 选择函数：`MultiTaskAdvancedSettings.OnGesturesPerSideSliderChanged`

4. **反馈延迟滑块**
   - 创建 Slider 组件
   - Min Value: 0.5
   - Max Value: 3
   - Whole Numbers: 关闭
   - Value: 1.5
   - 添加Text显示当前值
   - 在OnValueChanged事件中：
     - 拖入挂载了MultiTaskAdvancedSettings的GameObject
     - 选择函数：`MultiTaskAdvancedSettings.OnFeedbackDelaySliderChanged`

### 步骤3：添加设置脚本
1. 在场景中创建一个空GameObject，命名为"MultiTaskAdvancedSettings"
2. 添加 `MultiTaskAdvancedSettings` 脚本组件
3. 将这个GameObject拖到上面所有滑块的OnValueChanged事件中

### 步骤4：添加标签说明
为每个滑块添加Text标签，说明其用途：
- "回合时长（秒）"
- "总回合数"
- "每侧手势数量"
- "反馈延迟（秒）"

## 📝 注意事项

- 所有设置都会保存在 `AllSettingCtr` 单例中
- `AllSettingCtr` 使用了 `DontDestroyOnLoad`，会在场景切换时保持
- 如果没有配置设置UI，游戏会使用默认值
- 可以在Inspector中直接修改 `AllSettingCtr` 的默认值

## 🔧 可选：添加实时预览

如果想在滑块旁边显示当前值，可以添加以下代码到 `MultiTaskAdvancedSettings.cs`：

```csharp
[Header("UI显示（可选）")]
public Text roundDurationText;
public Text totalRoundsText;
public Text gesturesPerSideText;
public Text feedbackDelayText;

public void OnRoundDurationSliderChanged(float value)
{
    if (allSettingCtr != null)
    {
        allSettingCtr.multiTaskRoundDuration = value;
        if (roundDurationText != null)
            roundDurationText.text = value.ToString("F1") + "秒";
    }
}

// 其他方法类似...
```

然后在Inspector中拖入对应的Text组件即可实时显示数值。
